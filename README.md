## Features

- Responsive fintech homepage
- Modern and clean UI
- Interactive financial dashboard
- Week / Month / Year financial overview
- Responsive layout for desktop and mobile
- Product, Insights and How It Works sections
- Call-to-action sections
- Responsive navigation

## Design Approach

I designed the homepage around the idea of making personal finance simpler and easier to understand.

The visual direction uses:

- Minimal fintech aesthetics
- Clear typography
- Generous whitespace
- Soft green financial accents
- Dashboard-based visual storytelling
- Responsive layouts

The goal was to communicate Fermor as a product that helps users understand their finances, make better decisions and grow financially.
